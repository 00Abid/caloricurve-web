# Caloricurve-Web

A simple and visually appealing Calorie Tracker Web App built using **HTML**, **CSS**, and **JavaScript**. This app fetches nutritional data from a JSON file (`indian foods.json`) to display calorie and nutrient details of various foods.

## Features

- User authentication pages: Login and Signup
- Interactive calorie curve with animations
- Detailed nutrient information for Indian foods
- Responsive and clean user interface
- Data fetched dynamically from `indian foods.json`
- Easy to use and informative for tracking calorie intake

## Technologies Used

- HTML5
- CSS3 (including animations)
- JavaScript (DOM manipulation)
- JSON for food data storage

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- Optional: A local server to run the project smoothly (e.g., Live Server extension in VS Code)

### Installation

1. Clone the repository:
```git clone https://github.com/00Abid/caloricurve-web.git```

2. Open the project folder.

3. Open `index.html` in your browser

### Usage

- Use the signup page to create a new user.
- Login to access the calorie tracking interface.
- View and interact with the animated calorie curve.
- Explore nutrient information for Indian foods provided by the JSON dataset.
